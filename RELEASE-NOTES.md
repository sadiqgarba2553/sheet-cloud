# Sheet Cloud 0.2.0

Persistent range charts, static pivot summaries, live formula Goal Seek, text splitting, duplicate clearing and JSON exchange. Fixed XLSX merged-cell import, live-grid updates and responsive tools. Existing workbooks and green squircle branding are preserved. XLSX chart/pivot objects and full Excel parity are not included.

Windows x64 alpha. Public Windows publisher signing is not available. See docs/CODEX_VERIFICATION.md for tested behavior and known limitations. Back up important work using the native file format before updating.
