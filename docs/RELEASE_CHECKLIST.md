# Release checklist

- [x] Original Sheet Cloud branding and application shell.
- [x] Real grid/formula engine and local workbook persistence.
- [x] Native format and bounded XLSX/CSV compatibility.
- [x] Automated calculation, storage, conversion and UI checks.
- [x] Preserve original imported XLSX bytes locally.
- [x] Static REA evidence for the installed Excel executable.
- [x] Windows desktop build and runtime smoke check.
- [ ] Complete clean-machine EXE/MSI install/uninstall and native save/reopen tests.
- [ ] Sign Windows production packages.
- [ ] Run macOS Intel/Apple Silicon and Linux package/install tests; configure macOS signing and notarization.
- [ ] Implement native file-association launch handling.
- [ ] Expand formula and OOXML compatibility corpus.
- [ ] Add dedicated sorting, filtering, validation and conditional-formatting UI regression tests.
- [ ] Complete hostile-file resource bounds and native filesystem security review.
- [ ] Resolve incomplete published license metadata for `buffers@0.1.1` and complete distribution-license review.
- [ ] Profile startup, memory, large sheets and calculation responsiveness.
- [ ] Complete keyboard and assistive-technology accessibility review.
- [ ] Validate physical printing and advanced print settings.
- [ ] Implement embedded chart persistence/exchange, advanced workbook features and optional secure collaboration before advertising them.

The checked items are development milestones. They do not make the unchecked production gates complete.
